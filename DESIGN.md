## Overview

Agent Hub is a routing desk for a developer working with a particular coding harness. It is a conversation first, but the harness choice remains visible: people must always know where a draft will go and whether it can execute.

## Color and type

The cobalt switchboard is the product's single emphatic element; it holds routes and permission controls like a physical patch panel. The rest of the screen is cool paper so the task conversation stays readable. Use Avenir/system sans for the interface and reserve monospace for the selected harness command.

## Layout

Desktop uses a solid left-hand switchboard and one generous reading column. The route header reports the active harness and execution path. Conversation is left-aligned; user input is the only right-aligned speech shape. Mobile condenses routes into a horizontal chooser and keeps the conversation/composer intact.

## Components

Route selection uses a coloured marker and pressed state, never a generic card. The current route names its harness command. Assistant replies carry the harness they were sent to, so switching routes does not relabel earlier messages. The composer says that text is a draft until an execution path is connected.

## Do's and Don'ts

Do make routing and the execution boundary clear before asking a person to type. Do use the switchboard as the only dominant field of colour. Do keep errors concrete and state the recovery action. Do not add dashboard metrics, decorative terminal noise, fabricated run progress, generic hero copy, or repeated floating cards.
